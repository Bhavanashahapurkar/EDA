About the Project
This project explores a Loan Approval dataset using Python and Jupyter Notebook. It focuses on understanding the data, checking its structure, and identifying useful patterns.
Files
- EDA.ipynb – Notebook containing the analysis.
- loan_approved.csv – Dataset used for analysis.
Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
How to Run
1. Clone the repository:git clone https://github.com/Bhavanashahapurkar/EDA.git
2. Install the libraries:pip install pandas numpy matplotlib seaborn jupyter
3. Open EDA.ipynb in Jupyter Notebook and run the cells.
Learning Outcomes
- Loading and inspecting datasets
- Understanding columns and data types
- Exploring data and identifying patterns
- Practising Python libraries for data analysis
